# @ai-classroom/shared-types

Shared TypeScript type definitions and runtime Zod schemas for the **AI Interactive Classroom** ecosystem.

## Contents

- **Auth & Tenant**: User, School, Membership, Classroom schemas.
- **Room & Events**: Room lifecycle, participant tokens, room event payloads, sync envelopes.
- **Presenter & Device**: Device pairing, presenter requests, role permissions.
- **Activities**: Polls, quizzes, questions, answers, and group workspace schemas.
- **AI Contracts**: Job dispatch request/response models, embedding schemas, citation payloads.
