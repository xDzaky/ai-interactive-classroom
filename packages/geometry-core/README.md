# @ai-classroom/geometry-core

Mathematical calculation engine and geometric models for 3D solids in **AI Interactive Classroom**.

## Supported Solids

- **Prisms & Cuboids**: Volume, surface area, vertices, edge meshes, and net unfolding.
- **Cylinders & Cones**: Radial dimensions, lateral area, slant height, and parametric slicing.
- **Pyramids & Spheres**: Height, base polygons, cross-section planes, and bounding boxes.
- **Shared Test Fixtures**: Shared test vectors used for TS↔Python parity validation.
